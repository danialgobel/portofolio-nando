# Beneath the Surface — Underwater Diving & Photography Portfolio

An immersive, cinematic personal portfolio website dedicated to ocean exploration, scuba diving, and underwater photography.

> *"Every dive reveals a story the ocean has been keeping."*

---

## ✨ Features

- **Cinematic Opening Sequence**: Atmospheric depth descent counter with ultra-smooth veil dissolve and staggered hero typography bloom.
- **Buttery Fluid Scroll Motion**: Optical de-blurring (`filter: blur(...)`) and custom exponential easing curves across all editorial text lines and paragraphs.
- **Sticky Depth Journey**: Interactive multi-stage dive panel with synchronous underwater photography crossfades and live depth tracker HUD.
- **Horizontal Gallery**: Drag-and-scroll fluid photography gallery with full-resolution lightbox viewer and technical dive telemetry.
- **Underwater Audio Ambience**: Integrated hydrophone ambient sound synthesis and soundwave visualization toggle.
- **Responsive & Optimized**: Lossless landscape photography composition, optimized typography clamps, and zero-dependency vanilla architecture.

---

## 🚀 Deployment (Vercel)

This repository is pre-configured for instant zero-config deployment on [Vercel](https://vercel.com):

1. Push this repository to GitHub:
   ```bash
   git push -u origin main
   ```
2. In the Vercel dashboard, click **Add New Project** and select `portofolio-nando`.
3. Keep the default settings (Framework Preset: *Other*) and click **Deploy**.

- **HTML5**: Semantic document structure and accessibility
